# Fin-Tech News Hub

Personal financial news aggregator covering **Mag7**, **ELN underlyings**,
**Semiconductors**, **Taiwan Tech**, **AI**, and **Fed Rate** — bilingual UI
(Traditional Chinese / English).

Static site, refreshed every 15 minutes by GitHub Actions, served free by
GitHub Pages. **No backend at runtime.**

Live demo: `https://YOUR_USERNAME.github.io/REPO_NAME`

## Architecture

```
GitHub Actions (cron */15)
  └─ runs build.py
       ├─ fetches all RSS feeds            (config.py)
       ├─ classifies each article          (classify.py)
       └─ writes docs/data/articles.json + themes.json

GitHub Pages
  └─ serves docs/index.html + docs/data/*.json globally via CDN

Browser
  └─ fetches the JSON, renders, filters client-side
```

## Files

| File | Role |
|---|---|
| `config.py` | Theme keywords, group structure, RSS source list — **your tuning surface** |
| `classify.py` | Multi-label keyword classifier (rule-based) |
| `build.py` | Cron worker — fetches, classifies, writes JSON |
| `docs/index.html` | Frontend, vanilla JS — reads `docs/data/*.json` |
| `docs/data/` | Auto-generated by `build.py` (kept out of git via the workflow artifact path) |
| `.github/workflows/build.yml` | GitHub Actions — cron schedule, build, deploy |
| `requirements.txt` | Python deps (just `feedparser`) |

## Deployment (one-time setup)

1. **Create a GitHub repo** named e.g. `fintech-news-hub` (public — public repos get unlimited Actions minutes).

2. **Push this folder:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/fintech-news-hub.git
   git push -u origin main
   ```

3. **Enable Pages:** Repo → Settings → Pages → **Source: GitHub Actions**.

4. **Allow Actions to deploy:** Repo → Settings → Actions → General →
   *Workflow permissions* → **Read and write permissions**.

5. **Trigger the first build:** Repo → Actions → *Build & Deploy* → **Run workflow**.
   Or just wait up to 15 min for the cron.

6. After ~2 min, your site is live at:
   ```
   https://YOUR_USERNAME.github.io/fintech-news-hub
   ```

## Customizing

- **Add a ticker / theme:** edit `THEMES` in `config.py`, push, done.
- **Tune classifier sensitivity:** edit `W_HIGH`, `W_MED`, `THRESHOLD` in `classify.py`.
- **Change cron frequency:** edit the `cron:` line in `.github/workflows/build.yml`.
  Minimum is 5 min; recommended 10–15 to avoid being throttled by Google News.
- **Add an RSS source:** append to `RSS_SOURCES` in `config.py`.

## Classifier in one line

```
score(article, theme) = 3·(strong-keyword hits) + 1·(soft-keyword hits)
label  =  threshold ≥ 1.5  →  multi-label across themes
```

So **one strong hit** (e.g. `TSMC`, `FOMC`) **or two soft hits** (e.g. `chip` + `foundry`) tags the article. Articles with no theme match are dropped.

## Pitfalls

- **Google News rate limits.** Don't drop the cron below 5 min.
- **Cron is best-effort.** GitHub may delay or skip runs during peak load — actual cadence is 10–20 min, not exactly 15.
- **Each build is stateless.** The site shows whatever the RSS feeds currently expose (typically last 1–3 days). If you want longer history, commit `docs/data/articles.json` back to main on each run instead of using the artifact-deploy pattern.
- **`SNAP` ticker is deliberately excluded** as a bare keyword — too many false positives ("snap election", "snap decision"). Snap Inc. is matched via "Snap Inc" / "Snapchat" instead.
- **`Foundry` is a Palantir product** but also a semiconductor term. Excluded from PLTR's keywords to avoid bleed.

## Roadmap
